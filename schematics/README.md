# Schematics

this folder contains the schematics for all x86_64 instructions (insns.dat),
it is taken from https://repo.or.cz/nasm.git/blob_plain/HEAD:/x86/insns.dat and is a part of the nasm project.

## Usage

the primary usage of this file is for bitforge to be able to automatically generate code for each instruction instead of manually having to hardcode each and every single one.
